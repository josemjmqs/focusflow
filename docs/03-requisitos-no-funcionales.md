# Requisitos No Funcionales

## RNF-01: Rendimiento

La aplicación debe cargar su interfaz principal en un tiempo razonable y responder rápidamente a las acciones del usuario.

---

## RNF-02: Persistencia de datos

Las sesiones de concentración deben almacenarse de forma permanente en una base de datos PostgreSQL para evitar la pérdida de información.

---

## RNF-03: Usabilidad

La interfaz debe ser sencilla e intuitiva, permitiendo que cualquier usuario pueda iniciar una sesión de concentración sin necesidad de instrucciones.

---

## RNF-04: Diseño responsive

La aplicación debe adaptarse correctamente a dispositivos móviles, tablets y computadores.

---

## RNF-05: Disponibilidad

Mientras el servidor esté en funcionamiento, la aplicación debe permitir registrar y consultar sesiones sin interrupciones.

---

## RNF-06: Mantenibilidad

El código debe estar organizado en componentes y módulos para facilitar futuras modificaciones y la incorporación de nuevas funcionalidades.

---

## RNF-07: Compatibilidad

La aplicación debe funcionar correctamente en los navegadores modernos compatibles con los estándares actuales.

---

## RNF-08: Seguridad

Las solicitudes al servidor deben validarse para evitar el almacenamiento de datos inválidos y proteger la aplicación frente a errores comunes.
